## 3. Key ideas I understood (Password Security + Basic Cryptography)

### Password Security Concepts
- **Length**: Longer passwords are much harder to guess or brute-force.
- **Complexity**: Using a mix of uppercase, lowercase, numbers, and symbols increases the number of possible combinations.
- **Uniqueness**: Common passwords (like "admin" or "password") are easy for attackers to try first. They should always be rejected.
- **Reuse**: Using the same password in multiple places is dangerous. If one account is leaked, others become vulnerable.

### Basic Cryptography Concepts related to this task
- **Entropy**:  
  Entropy measures how unpredictable a password is.  
  Higher entropy means the password is harder to crack.  
  We calculate it roughly as:  
  Entropy = Length × log2(character pool size)

- **Brute-force attacks**:  
  An attacker tries every possible combination until they find the correct password.  
  Longer passwords with higher entropy take much longer to crack.

- **Dictionary / Common password attacks**:  
  Attackers first try lists of commonly used passwords.  
  That is why we check against a common password list.

- **Password strength checking vs Password storage**:  
  This tool only *checks* strength.  
  In real systems, passwords should never be stored in plain text.  
  They should be stored using cryptographic hashing (one-way transformation).
